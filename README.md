# Summer 2026 Game

p5.js + TypeScript を使ったWebゲーム制作のサンプルプロジェクトです。

開発環境の準備からゲーム制作、GitHub Pagesへのデプロイまでをまとめたドキュメントも公開しています。

- Docs: https://akTARDIGRADE13-sandbox.github.io/summer-2026-game/docs/

## Sample Game

サンプルとして、敵を避けながらアイテムを集めるシンプルなゲームを実装しています。

主に以下の要素を扱っています。

- p5.jsによる描画
- キーボード入力
- ゲームループ
- プレイヤー・敵・アイテムの管理
- 衝突判定
- スコア
- ゲーム状態
- GitHub Pagesへのデプロイ
