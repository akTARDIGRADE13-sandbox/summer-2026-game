4. Webページを編集する

Viteで作成したプロジェクトには、 Webページを作るためのHTML、CSS、TypeScriptが含まれています。

このチュートリアルでは、それぞれの言語の文法そのものは 詳しく扱いません。 ここでは、それぞれが何を担当しているのかと、 プロジェクト内でどのようにつながっているのかを確認します。

4.1 Webページを構成するもの

今回は、主に次の3つを使ってWebページを作ります。

言語 主な役割
HTML ページの構造や内容を記述する
CSS 色、余白、配置などの見た目を指定する
TypeScript ユーザー操作への反応など、ページの処理を記述する

大まかには、 HTMLが構造、CSSが見た目、TypeScriptが処理 を担当すると考えておけば十分です。

TypeScriptとJavaScript

TypeScriptはJavaScriptを拡張した言語です。 ブラウザが最終的に実行するのはJavaScriptなので、 ViteがTypeScriptをブラウザで利用できる形に変換します。

4.2 HTMLを見る

プロジェクトのルートにある index.html がWebページの入口になります。

例えば、最小限のページは次のように書けます。

<!doctype html>
<html lang="ja">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>My Game</title>
  </head>

  <body>
    <main>
      <h1>My Game</h1>
      <p>ゲームを作ってみよう！</p>
    </main>

    <script type="module" src="/src/main.ts"></script>
  </body>
</html>

<h1> や <p> のようなものを HTML要素と呼びます。

今回すべてのHTML要素を覚える必要はありません。 必要なものが出てきたときに調べながら使えば十分です。

最後の <script> では、 このページから読み込むTypeScriptファイルを指定しています。 

<script type="module" src="/src/main.ts"></script>

4.3 CSSを見る

CSSでは、HTMLで作った要素の見た目を指定します。

例えば、次のCSSを考えます。

body {
  margin: 0;
}

main {
  max-width: 960px;
  margin: 0 auto;
  padding: 32px;
}

この例では、ページ全体の余白を調整し、 <main> の幅や配置を設定しています。

CSSはTypeScriptから読み込むこともできます。

import "./style.css";

ViteがCSSを処理し、ブラウザから利用できる形にしてくれます。

このサイト自体も、基本的にはHTMLとCSSを使ってレイアウトしています。 Webページのデザインを変更したい場合は、 このサイトのHTMLやCSSも参考にしてみてください。

4.4 TypeScriptを見る

TypeScriptでは、ページ上で行いたい処理を書きます。

例えば、HTML内に次のボタンがあるとします。

<button id="hello-button">Click</button>

TypeScriptからこのボタンを取得し、 押されたときの処理を書くことができます。 

const button = document.querySelector("#hello-button");

button?.addEventListener("click", () => {
  console.log("Hello!");
});

このように、TypeScriptを使うことで ユーザーの入力に応じてページを動かすことができます。

p5.jsを利用するゲームもTypeScriptから動かします。 p5.jsについては次の章で扱います。

文法を全部理解してから進む必要はありません

const、 function、 配列、クラス、型など、 TypeScriptにはさまざまな文法があります。 分からない構文が出てきたときに、その都度調べながら進めて構いません。

4.5 Viteの初期ページを整理する

Viteが最初に生成するプロジェクトには、 動作確認用のサンプルコードや画像が含まれています。

今回はゲームを作るので、 これらを削除して最小限の状態にしておきます。

index.html は、例えば次のようにできます。

<!doctype html>
<html lang="ja">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>My Game</title>
  </head>

  <body>
    <main>
      <h1>My Game</h1>
      <div id="game-container"></div>
    </main>

    <script type="module" src="/src/main.ts"></script>
  </body>
</html>

src/main.ts も、 Viteが生成したサンプルコードを削除して、 ひとまずCSSだけ読み込む状態にできます。 

import "./style.css";

src/style.css は、 例えば次の程度から始められます。 

body {
  margin: 0;
}

main {
  max-width: 960px;
  margin: 0 auto;
  padding: 32px;
}

#game-container {
  display: flex;
  justify-content: center;
}

#game-container は、 次の章でp5.jsのCanvasを配置するために使用します。

編集できたら、開発サーバを起動して確認します。

npm run dev

ブラウザに My Game と表示されればOKです。
