9. 発展・参考資料

ここまでで、p5.jsとTypeScriptを使ったゲームの作成から、 GitHub Pagesでの公開まで一通り行えるようになりました。

この章では、さらにゲームやWebページを発展させたい場合の 選択肢と参考資料を紹介します。

全部使う必要はありません

ここで紹介するものは、ゲーム制作に必須ではありません。 自分が作りたいものに必要になったときに、 興味のあるものから調べてみてください。

9.1 Webページのデザイン

ゲームそのものだけでなく、 ゲームを公開するWebページのデザインも自由に変更できます。

CSSを使う

このサイト自体も、基本的にはHTMLとCSSだけで レイアウトやデザインを作っています。

例えば、次のようなCSSの機能を調べてみると、 かなり自由にページを作れるようになります。

  • Flexbox
  • CSS Grid
  • レスポンシブデザイン
  • CSS Custom Properties（CSS変数）
  • transition / animation

このドキュメントのサイドバーも、 CSS Gridを使って本文と横に並べています。

Bootstrapを使う

CSSをすべて自分で書く代わりに、 Bootstrapのような CSSフレームワークを利用する方法もあります。

Bootstrapには、ボタン、カード、ナビゲーション、 グリッドレイアウトなどのスタイルがあらかじめ用意されています。

例えば、通常のHTMLで

<button>Restart</button>

と書く代わりに、Bootstrapを導入したページでは 次のようなclassを利用できます。 

<button class="btn btn-primary">
  Restart
</button>

btn や btn-primary に対応するスタイルが Bootstrap側で用意されています。

ゲーム画面の周りにナビゲーションや説明、 スコア表示などを作り込みたい場合に便利です。

Bootstrap

まずは素のHTML / CSSでも十分です

Bootstrapを使う必要があるわけではありません。 小さなWebページであれば、 HTMLとCSSだけで作った方が構造を理解しやすいこともあります。

9.2 p5.jsをさらに使う

サンプルゲームでは、 円や文字などのシンプルな描画だけを使用しました。

p5.jsには、さらにさまざまな機能があります。

画像を使う

図形の代わりに画像を使うと、 プレイヤーや敵の見た目を自由に作れます。 

let playerImage: p5.Image;

p.preload = () => {
  playerImage = p.loadImage("player.png");
};

p.draw = () => {
  p.image(playerImage, x, y);
};

音を使う

効果音やBGMを追加すると、 ゲームの印象を大きく変えることができます。

音声を扱いたい場合は、 p5.jsのSound関連の機能について調べてみてください。

p5.Vector

今回はx方向とy方向を別々の変数で管理しましたが、 位置や速度をベクトルとして扱う方法もあります。 

const position = p.createVector(320, 240);
const velocity = p.createVector(100, 0);

position.add(velocity);

移動方向や速度を多く扱うゲームでは便利です。

アニメーション

複数の画像を切り替えたり、 図形の大きさや色を時間とともに変化させたりすると、 キャラクターやエフェクトをアニメーションさせられます。

WebGL

p5.jsでは2D描画だけでなく、 WebGLを利用した3D描画も可能です。 

p.createCanvas(640, 480, p.WEBGL);

ただし3Dでは、カメラ、座標系、光源など 2Dとは異なる知識も必要になります。 最初から無理に使う必要はありません。

詳しい機能については公式Referenceを参照してください。

p5.js Reference

9.3 開発環境を便利にする

これまでのチュートリアルでは、 できるだけ標準的でシンプルな開発環境を使いました。

開発に慣れてきたら、 自分が使いやすいように環境をカスタマイズすることもできます。

Shellを変更する

WSLでは標準のbash以外にも、 さまざまなShellを利用できます。

  • zsh
  • fish

補完や履歴検索など、 ターミナル操作を便利にする機能を利用できます。

プロンプトを変更する

Starshipなどを使うと、 現在のGit branchやNode.jsのバージョンなどを ターミナル上に表示できます。

Starship

VS Codeをカスタマイズする

VS Codeにも多数の拡張機能があります。

例えば、コードの整形、Git操作、 カラーテーマなどを自分の好みに合わせて変更できます。

ただし、拡張機能を大量に入れる必要はありません。 「この操作をもっと便利にしたい」と思ったときに 探してみるのがおすすめです。
