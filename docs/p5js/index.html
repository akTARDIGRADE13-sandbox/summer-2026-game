5. p5.jsを使う

p5.jsは、 ブラウザ上で図形や画像を描画したり、 キーボードやマウスからの入力を扱ったりできるJavaScriptライブラリです。

この章では、今回のゲーム制作で使用する基本的な機能を紹介します。 p5.jsにはほかにも多くの機能があるので、 必要になったものは公式Referenceを調べながら使ってみてください。

5.1 p5.jsを動かす

前の章までで作成した src/main.ts を、次のように書き換えてみます。 

import p5 from "p5";

new p5((p) => {
  p.setup = () => {
    p.createCanvas(640, 480);
  };

  p.draw = () => {
    p.background(240);
    p.circle(p.mouseX, p.mouseY, 50);
  };
});

開発サーバを起動します。

npm run dev

640 × 480の領域が表示され、 マウスカーソルに合わせて円が動けば成功です。

前の章で作成した #game-container の中にCanvasを配置する場合は、 次のように書けます。 

p.setup = () => {
  const canvas = p.createCanvas(640, 480);
  canvas.parent("game-container");
};

5.2 setup()とdraw()

p5.jsでは、 setup() と draw() が基本的な役割を持っています。

関数 役割
setup() 開始時に一度だけ実行される
draw() 実行中に繰り返し呼ばれる

Canvasの作成など、一度だけ行えばよい処理は setup() に書きます。 

p.setup = () => {
  p.createCanvas(640, 480);
};

一方、キャラクターの移動や画面の描画など、 ゲーム中に繰り返したい処理は draw() に書きます。 

p.draw = () => {
  p.background(240);

  // 状態を更新する
  // 画面を描画する
};

background() はCanvas全体を指定した色で塗ります。 毎フレーム最初に呼ぶことで、 前のフレームに描いた図形を消しています。

なぜ繰り返し描画するのか

ゲームでは、 「状態を少し更新して画面を描き直す」 という処理を高速に繰り返すことで、 キャラクターが動いているように見せます。 この繰り返しをゲームループと呼ぶことがあります。

5.3 Canvasと描画

座標

p5.jsのCanvasでは、 左上が原点 (0, 0) になります。

(0, 0) ─────────────→ x
  │
  │
  │
  ↓
  y

x座標は右へ行くほど大きくなり、 y座標は下へ行くほど大きくなります。

図形を描く

例えば、円は次のように描けます。

p.circle(320, 240, 50);

この例では、 (320, 240) を中心として、 直径50の円を描画しています。

長方形は次のように描けます。

p.rect(100, 100, 80, 40);

色を指定する

fill() で、その後に描画する図形の色を指定できます。 

p.fill(50, 100, 220);
p.circle(320, 240, 50);

このように3つの値を指定した場合は、 RGBの赤・緑・青を表します。

background() でも同様に色を指定できます。

p.background(240);

値を1つだけ指定した場合はグレースケールになり、 0 が黒、 255 が白です。

文字を描く

スコアなどの文字もCanvasへ描画できます。

p.fill(30);
p.textSize(24);
p.text("Score: 10", 16, 32);

5.4 キーボードとマウス

マウスの位置を取得する

現在のマウスカーソルの座標は、 mouseX と mouseY から取得できます。 

p.circle(p.mouseX, p.mouseY, 50);

押されているキーを調べる

キーを押している間キャラクターを動かしたい場合は、 keyIsDown() が便利です。 

if (p.keyIsDown(87)) {
  y -= 1;
}

87 はWキーのキーコードです。 矢印キーについては、例えば次のように書けます。 

if (p.keyIsDown(p.LEFT_ARROW)) {
  x -= 1;
}

この処理を draw() の中で繰り返すことで、 キーを押している間、連続してキャラクターを動かせます。

キーが押された瞬間を扱う

「Spaceキーを押したらゲーム開始」のように、 キーを押した瞬間に一度だけ処理したい場合は keyPressed() を利用できます。 

p.keyPressed = () => {
  if (p.key === " ") {
    console.log("Start!");
  }
};

今回のサンプルゲームでも、 移動には keyIsDown()、 ゲーム開始やリスタートには keyPressed() を使い分けています。

5.5 ゲームで便利な機能

今回のサンプルゲームでは、 p5.jsのいくつかの便利な機能も使用しています。

random()

ランダムな値を生成します。

const x = p.random(0, 640);
const y = p.random(0, 480);

アイテムや敵の出現位置をランダムにするときなどに利用できます。

dist()

2点間の距離を求めます。

const distance = p.dist(x1, y1, x2, y2);

今回のゲームでは、 プレイヤーと敵やアイテムとの衝突判定に使用します。

constrain()

値を指定した範囲内に収めます。

x = p.constrain(x, 0, 640);

プレイヤーがCanvasの外へ出ないようにするときなどに利用できます。

deltaTime

deltaTime には、 前のフレームから現在のフレームまでに経過した時間が ミリ秒単位で入っています。 

const dt = p.deltaTime / 1000;

x += speed * dt;

このように経過時間を使って移動量を計算すると、 フレームレートが変わっても キャラクターの移動速度をほぼ一定にできます。

5.6 Referenceを使う

p5.jsには非常に多くの関数や機能があります。 すべてを覚える必要はありません。

「円を描きたい」「画像を表示したい」「キー入力を扱いたい」 といった必要が出てきたときに、 p5.jsの公式Referenceを検索して使い方を確認するのがおすすめです。

p5.js Reference

例えば、この章で使用した circle()、 keyIsDown()、 random()、 dist() などもReferenceから確認できます。

画像、音声、より複雑な描画などを使いたくなった場合も、 まずReferenceから関連する機能を探してみてください。
