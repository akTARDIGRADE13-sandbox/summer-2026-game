3. プロジェクトを作る

ここでは、Viteを使ってTypeScriptのWebプロジェクトを作成し、 ブラウザで動作を確認します。 最後に、ゲーム制作で使用するp5.jsを追加します。

3.1 Viteでプロジェクトを作る

Viteは、 Webアプリケーションの開発やビルドを行うためのツールです。 今回はViteを使ってTypeScriptプロジェクトを作成します。

まず、プロジェクトを置きたいディレクトリへ移動します。 例えば、前の章で作成した ~/projects を使用する場合は次のようにします。 

cd ~/projects

次に、ゲーム用のディレクトリを作成して移動します。

mkdir my-game
cd my-game

ディレクトリ内で、次のコマンドを実行します。

npm create vite@latest .

. は現在のディレクトリを表します。 そのため、このコマンドでは現在のディレクトリに Viteプロジェクトを作成しています。

いくつか選択肢が表示されるので、今回は次のように選択します。

  • Framework: Vanilla
  • Variant: TypeScript
Vanillaとは

ReactやVueなどのフレームワークを使わず、 HTML、CSS、TypeScriptを基本として開発する構成です。 今回はWebページの構造を分かりやすくするため、 Vanillaを使用します。

3.2 パッケージをインストールする

プロジェクトを作成したら、必要なパッケージをインストールします。 

npm install

このコマンドを実行すると、 package.json に記載されているパッケージが node_modules にインストールされます。

ここでは、パッケージを 「プロジェクトで利用するライブラリや開発ツールをまとめたもの」 くらいに考えておけば十分です。

node_modulesについて

node_modulesにはインストールされたパッケージが保存されます。 多数のファイルが含まれますが、基本的に中身を直接編集する必要はありません。

3.3 開発サーバを起動する

プロジェクトが作成できたら、開発サーバを起動します。

npm run dev

ターミナルに、次のようなURLが表示されます。

http://localhost:5173/

URLをブラウザで開き、Viteの初期ページが表示されれば成功です。

ファイルを編集して保存すると、 多くの場合ブラウザ側にも変更がすぐ反映されます。 開発中は基本的に、この開発サーバを起動したまま作業します。

開発サーバを終了するときは、 起動しているターミナルで Ctrl + C を押します。

3.4 ファイル構成を見る

Viteで作成した直後のプロジェクトには、 いくつかのファイルやディレクトリがあります。 

my-game/
├── public/
├── src/
├── index.html
├── package.json
├── package-lock.json
└── tsconfig.json

今の段階では、それぞれの細かい内容を覚える必要はありません。 主に次のファイルを編集していきます。

ファイル・ディレクトリ 役割
index.html Webページの基本的な構造を書く
src/ TypeScriptやCSSなどのソースコードを置く
public/ 画像など、そのまま公開したいファイルを置く
package.json 使用するパッケージや npm run dev などのコマンドを定義する
package-lock.json インストールするパッケージのバージョンなどをnpmが記録する
tsconfig.json TypeScriptの設定を書く

このほかに node_modules/ も作成されていますが、 基本的に自分で編集することはありません。

3.5 p5.jsを追加する

最後に、ゲーム制作で使用する p5.js をプロジェクトへ追加します。 

npm install p5

これで、TypeScriptのコードからp5.jsを利用できるようになります。

package.jsonを見ると、 p5.jsがプロジェクトの依存パッケージとして追加されていることを確認できます。
