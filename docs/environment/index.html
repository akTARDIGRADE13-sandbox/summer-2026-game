2. 開発環境を準備する

ここでは、ゲーム開発を始めるために必要な開発環境を準備します。 Windows上にWSLを導入し、Node.jsやVS Codeを利用できるようにします。

2.1 WSLをセットアップする

この企画では、Windows上の開発環境として WSL（Windows Subsystem for Linux） を使用します。 WSLを使うと、Windows上でUbuntuなどのLinux環境を利用できます。

WSLをインストールする

PowerShellを管理者として起動し、 次のコマンドを実行します。 

wsl --install

インストールが完了したら、必要に応じてPCを再起動してください。 Ubuntuを初めて起動すると、Linux上で使用するユーザー名と パスワードの設定を求められます。

wsl --install がうまく動かない場合

WSL自体が古い場合があります。 次のコマンドでWSLを更新してから、もう一度試してください。 

wsl --update

インストールできるLinuxディストリビューションの一覧は、 次のコマンドで確認できます。 

wsl --list --online

ディストリビューションを指定してインストールする場合は、 次のようにします。 

wsl --install -d <Distribution Name>

例えばUbuntu 24.04を指定する場合は次のようになります。

wsl --install -d Ubuntu-24.04

これらの方法でもうまくいかない場合は、 Microsoft公式のWSLドキュメントを参照してください。

WSLのインストール | Microsoft Learn

2.2 ターミナルを使う

WSLでは、ターミナルからコマンドを入力して、 ディレクトリの移動やプログラムの実行などを行います。 最初から多くのコマンドを覚える必要はありません。

コマンド 役割
pwd 現在いるディレクトリを表示する
ls ファイルやディレクトリを一覧表示する
cd ディレクトリを移動する
mkdir ディレクトリを作成する
cp ファイルやディレクトリをコピーする
mv ファイルを移動する・名前を変更する
rm ファイルを削除する

また、パスでは次の表記をよく使用します。

表記 意味
~ 自分のホームディレクトリ
. 現在のディレクトリ
.. 1つ上のディレクトリ

作業用ディレクトリを作る

プロジェクトはWSL側のホームディレクトリ以下に 置くことをおすすめします。 

mkdir -p ~/projects
cd ~/projects

現在いる場所は次のコマンドで確認できます。

pwd

ターミナルのカスタマイズ

このチュートリアルでは標準の環境を使用しますが、 ターミナルの見た目や操作方法は自由にカスタマイズできます。 興味があれば、zsh、fish、Starshipなどについて調べてみてください。

2.3 Node.jsをインストールする

Node.jsは、 JavaScriptをブラウザ以外の環境でも実行できるようにする実行環境です。

Node.jsではnpmというパッケージマネージャーを利用できます。 今回使用するViteやp5.jsなどもnpmを使って導入します。

Node.jsのインストールには nvm（Node Version Manager） を使用します。

nvmをインストールする

nvmのインストール方法は、公式リポジトリを参照してください。

nvm - Installing and Updating

インストール後、nvmが利用できることを確認します。

command -v nvm

nvm と表示されればOKです。

Node.jsをインストールする

Node.jsのLTS版をインストールします。

nvm install --lts

インストール後、それぞれのバージョンを確認します。

node --version
npm --version

両方ともバージョン番号が表示されれば準備は完了です。

2.4 VS Codeを準備する

このチュートリアルでは、コードを書くためのエディタとして Visual Studio Code（VS Code） を使用します。

VS CodeはWindows側にインストールします。 また、VS CodeからWSL上のファイルを扱うために WSL拡張機能をインストールしてください。

Visual Studio Code

WSLからVS Codeを起動する

WSLのターミナルで、開きたいディレクトリへ移動してから 次のコマンドを実行します。 

code .

. は「現在のディレクトリ」を意味します。 つまり、code . は 「現在のディレクトリをVS Codeで開く」という意味です。
